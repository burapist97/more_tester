Install requirements;
Node.js
Appium
Phyton
Streamlit
Appium Inspector
Adb

Connect your phone with adb connection
Start appium in cmd
Open and connect Appium inspector
Open the web sites
Choose your action and copy your appium inspector xpatxh 
Your own appium test automation is ready!
